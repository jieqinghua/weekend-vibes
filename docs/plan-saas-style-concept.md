# SaaS 风格作品集设计图计划

## 目标与范围

- 为当前 Vibe Coding 个人作品集生成一张新的 1440px 桌面长页效果图。
- 视觉语言与配色参考 `https://www.designprompts.dev/saas`。
- 保留当前站点的核心信息：个人介绍、项目卡片、视频入口、GitHub / Notion 链接、联系信息。
- 本轮仅生成设计图，不修改现有页面代码。

## 执行步骤及状态

1. **已完成** — 截取并分析参考站与当前作品集页面。
2. **已完成** — 提炼可复用的配色、排版、卡片与按钮规范。
3. **已完成** — 生成一张独立的桌面长页设计效果图。
4. **已完成** — 检查信息层级、中文文案可读性与整体一致性，并输出预览成品。
5. **已完成** — 根据反馈移除所有现有项目之外的新增内容，生成严格内容对齐的第二版。

成品文件：`docs/designs/portfolio-saas-tech-style-v1.png`、`docs/designs/portfolio-saas-tech-style-v2.png`

## 关键决策

- 使用参考站作为视觉风格基准，但不照搬品牌文字或业务内容。
- 维持个人作品集属性，不把页面改造成通用 SaaS 产品官网。
- 设计图以静态视觉评审为目的，交互状态只通过清晰的按钮和入口表达。
- 首轮只生成 1 个方向，符合用户本次明确要求。
- 采用参考站公开规范中的暖白 `#FAFAFA`、深石板 `#0F172A` 与电光蓝渐变 `#0052FF → #4D7CFF`。
- 字体系统参考 Calistoga / Inter / JetBrains Mono 的角色分工，并针对中文使用同类气质的字形呈现。
- 第二版以当前 `App.tsx` 与 `src/data/projects.ts` 为唯一内容来源；参考站只影响视觉，不影响信息架构和文案。
- 明确移除第一版新增的导航项、英雄区按钮与插画、数据指标、关于我模块、能力列表和额外页脚文案。

## 风险或待确认事项

- 生成式设计图中的小字号中文可能存在细节偏差，最终开发时应以真实网页文本为准。
- 如果参考站存在动态或登录后内容，本轮只采用公开可见页面作为依据。
