# SaaS 风格作品集设计图计划

## 目标与范围

- 为当前 Vibe Coding 个人作品集生成一张新的 1440px 桌面长页效果图。
- 视觉语言与配色参考 `https://www.designprompts.dev/saas`。
- 保留当前站点的核心信息：个人介绍、项目卡片、视频入口、GitHub / Notion 链接、联系信息。
- 本轮仅生成设计图，不修改现有页面代码。

## 执行步骤及状态

1. **进行中** — 截取并分析参考站与当前作品集页面。
2. **待执行** — 提炼可复用的配色、排版、卡片与按钮规范。
3. **待执行** — 生成一张独立的桌面长页设计效果图。
4. **待执行** — 检查信息层级、中文文案可读性与整体一致性，并保存成品。

## 关键决策

- 使用参考站作为视觉风格基准，但不照搬品牌文字或业务内容。
- 维持个人作品集属性，不把页面改造成通用 SaaS 产品官网。
- 设计图以静态视觉评审为目的，交互状态只通过清晰的按钮和入口表达。
- 首轮只生成 1 个方向，符合用户本次明确要求。

## 风险或待确认事项

- 生成式设计图中的小字号中文可能存在细节偏差，最终开发时应以真实网页文本为准。
- 如果参考站存在动态或登录后内容，本轮只采用公开可见页面作为依据。
